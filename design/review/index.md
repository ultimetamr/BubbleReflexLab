# Human Review Package · BubbleReflexLab

## Role documents

- `pm-requirement-spec.md` — 产品意图与质量契约
- `uxr-research-report.md` — 五类证据、竞品基线与领域模型
- `interaction-spatial-spec.md` — 任务、空间概念、容器、状态、交互与动效
- `visual-system-spec.md` — 视觉方向、组件八段结构、语义与资产约束
- `design-critique-report.md` — 独立评审、硬门与状态推导
- `preview-qa-report.md` — Web 设计验证原型覆盖与 QA
- `execution-trace.md` — 17 阶段执行收据
- `../preview.html` — 单文件、仅 Web 设计验证原型

## Boundary conventions

- 本包只描述 PICO Spatial 设计事实；不生成 Android/PICO 运行时代码。
- Preview 只验证状态、交互与响应式映射，不构成真机舒适度、遮挡、输入命中、性能或音频验证。
- 容器术语使用 Shared Space / Full Space、WindowContainer Planar / Volumetric、Stage Mixed / Progressive / Full。
